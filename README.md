# Bronicraft

Игра в стиле Майнкрафта прямо в браузере: строй, добывай, крафти, катайся на машинах и самолётах.

## Как запустить

Нужен любой простой веб-сервер в папке с игрой, например:

```bash
python3 -m http.server 8137
```

Потом открой в браузере http://localhost:8137

## Что есть

- Выживание и творчество, сложность от мирной до сложной, свой скин и ник
- Крафт, верстак, печка, сундуки, факелы, вёдра, вода и лава, которые растекаются
- Мобы, деревни, пещеры с рудами, коралловые рифы
- Карты: Город, Реалистичная деревня, Улица Ленина, Три новых ЖК, Русский город, Дома на Москве-реке, ЖК «Самоцветы»
- Моды: шейдеры, машины, самолёты, метро, лифт, телефон, компьютер, мини-мир, физган, World changing, камеры, превращения, реалистичный транспорт
- Управление на телефоне и планшете
